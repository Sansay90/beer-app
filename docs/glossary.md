# Словарь

Термины, которые встречаются в коде, документации и интерфейсе.

## Пиво

| Термин | Что это |
|---|---|
| **OG** | начальная плотность — сусла до задачи дрожжей; в коде — SG (1.048), в интерфейсе — °P или SG |
| **FG** | конечная плотность — после брожения |
| **SG, °P** | плотность: удельный вес (1.048) или градусы Плато (12 °P) — доля экстракта по массе |
| **ABV** | крепость, % об. |
| **IBU** | горечь; считается по Tinseth |
| **EBC** | цвет; у солода и у пива. SRM ≈ EBC / 1,97; °L — для формулы цвета Morey |
| **Засыпь** | солод и другое сбраживаемое сырьё рецепта (`fermentables`) |
| **Эффективность** | какая доля экстракта засыпи попадает в сусло после кипячения, % |
| **Сбраживание** (attenuation) | какую долю экстракта съедают дрожжи, % |
| **Затирание, пауза** | выдержка засыпи в воде при заданной температуре; программа пивоварни — паузы и кипячение |
| **Гидромодуль** | сколько литров заторной воды на килограмм засыпи |
| **Промывка** | вода, которой вымывают экстракт из дробины после затирания |
| **Закладка** | что кладут в кипячение и когда: «за 15 мин до конца» |
| **Первое сусло** | хмель, заложенный до кипячения: горчит всё кипячение |
| **Вирпул** | хмель, заложенный в конце кипячения и выдержанный N минут, — аромат без горечи |
| **Сухое охмеление** | хмель в брожение, на N-й день |
| **BJCP** | руководство по стилям пива; рамки стиля (OG, FG, IBU, цвет, крепость) — из BJCP 2021 |

## Пивоварня

| Термин | Что это |
|---|---|
| **Easy Brew Connect** | автоматическая пивоварня с Wi-Fi (модуль Tuya); штатное приложение — Smart Life |
| **Tuya, DP** | платформа модуля связи; DP (data point) — пронумерованные параметры пивоварни: температура, шаг, таймер… — [agent/PROTOCOL.md](../agent/PROTOCOL.md) |
| **Программа** | шаги пивоварни: паузы затирания и кипячение — температура, минуты, мощность |
| **Таймер закладки** | минута кипячения, на которой пивоварня пищит; до 9 разных минут |
| **Подсказка** | пивоварня ждёт человека: «засыпьте солод», «конец затирания» |
| **Ручной режим** | нагрев до температуры на время, без программы |
| **Ограничения** (limits) | что пивоварня примет: шагов, закладок, температуры, мощность и её шаг |
| **Профиль оборудования** | эффективность для новых рецептов и испарение при кипячении |

## Система

| Термин | Что это |
|---|---|
| **Сервис** | `service/` — сайт, API и база; пивоварню не видит |
| **Агент** | `agent/` — программа рядом с пивоварней: говорит с ней по домашней сети и сама подключается к сервису |
| **Варка** (brew) | запись о работе пивоварни: от запуска программы рецепта до её конца — температура, события, исход |
| **Снимок** (snapshot) | текущее состояние пивоварни для экрана: температура, шаг, таймер, закладки |
| **Событие** (event) | что случилось: шаг, подсказка, закладка, конец, ошибка, связь |
| **Запись** агента | событие, температура или варка с номером `seq`; держится у агента, пока сервис не подтвердит |
| **Опубликованный рецепт** | видят все, и гости; личный — только автор |
| **Общие примеры** | `shared/` — рецепты с ожидаемыми показателями и программой; по ним проверяют себя сервис и интерфейс |
