# Направления дизайна

Три варианта своего визуального языка вместо стандартного дашборда Nuxt UI (27.10.2026). В каждом макете — каталог рецептов, верх страницы рецепта American IPA и образец стиля (палитра, шрифты, кнопки, поля, фрагмент второй темы). Макеты статичные: HTML с CSS и SVG внутри, шрифты — Google Fonts. Логотип подгоняется под выбранное направление потом ([brand/](../brand/README.md)).

| | Направление | Идея | Тема | Шрифты |
|---|---|---|---|---|
| А | [Варочный журнал](./a-brew-log.html) | лабораторный журнал на миллиметровке; мерные шкалы работают: у каждого рецепта оси ABV / IBU / EBC с рамками стиля по BJCP — видно «в стиле / вне стиля»; ареометр OG→FG, график затирания, таймлайн кипячения | светлая | Sofia Sans Condensed + IBM Plex Sans |
| Б | [Тап-лист](./b-tap-list.html) | каталог как доска кранов в баре: строки, бокалы в цвет пива, крупные ABV / IBU, читаемые издалека; акцент — спектр цвета пива от соломы до чёрного | тёмная | Alumni Sans + Literata |
| В | [Этикетка](./c-label.html) | каждый рецепт — этикетка своего пива: рамка, штамп, лента с цифрами; эмблема 11б в шапке, её лента повторяется под показателями рецепта | светлая | Bitter + Oswald + Golos Text |

Картинки: `a-brew-log.png`, `b-tap-list.png`, `c-label.png` (десктоп 1280) и `*-mobile.png` (390 px).

Общее у всех: бокал по форме стиля, цвет пива — по EBC (стаут почти чёрный), короткое описание вкуса.

## Выбрано: Б, с карточками рецептов как на нынешнем сайте

Из трёх пользователю ближе Б; каталог — не строками тап-листа, а нынешними карточками (`web/app/components/recipe/RecipeCard.vue`: бокал, отсвет цвета пива, описание, цифры, фото) в палитре и шрифтах Б.

Навигация — [b-navigation.html](./b-navigation.html) (`b-navigation.png`, `b-navigation-mobile.png`), чтобы шапка не переполнялась с новыми разделами:

- наверху четыре хаба — **Рецепты, Варка, Склад, Справочник**; новое добавляется вкладкой внутрь хаба (вторая строка шапки), хабов не больше пяти;
- личное — в меню аккаунта: мои пивоварни, профиль, настройки, уведомления, пользователи (администратору), выход;
- поиск один на сайт (рецепты, ингредиенты, разделы), идущая варка видна в шапке из любого раздела;
- на телефоне хабы — нижняя панель, вкладки хаба — прокручиваемая строка сверху.

Страница варки (партии) — [b-batch.html](./b-batch.html) (`b-batch.png`, `b-batch-mobile.png`), 29.10.2026: одна страница для кастрюли и Easy Brew — варка в кастрюле и на автоматике не отличается ничем, кроме автоматики. Рецепт загружается на страницу и подстраивается под оборудование; варка — таймлайн из рецепта партии (подготовка → нагрев → засыпь → паузы → промывка → кипячение с закладками → охлаждение → дрожжи), дальше по той же линии брожение и розлив; замеры — на шаге, где их делают; блок «Сейчас» — текущий шаг и таймер (на кастрюле — сервис и push, на Easy Brew — таймер пивоварни и живая температура); вкладки «Варка · Брожение · Журнал · Рецепт партии» — разделы одной страницы. Заменяет экран «Варка» (b-brew.html), сделанный только под Easy Brew.

Шрифт названий, цифр и навигации — **Fira Sans Extra Condensed** (600 — названия и навигация, 700 — кнопки, цифры с `tabular-nums`); описания — Literata. Alumni Sans из первых макетов отброшен: тесный пробел, на длинных названиях слова сливаются. Сравнение шести кандидатов — [b-fonts.html](./b-fonts.html).
